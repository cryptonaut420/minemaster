# MineMaster 1.4.6

Reporting and update reliability follow-up, preserving the direct admin Play/Pause controls and Windows Nanominer file reporting.

- Nanominer's ten-minute averages no longer overwrite current speed or refresh stale readings.
- Delayed share and pool logs retain their original observation timestamps.
- Local/admin update installation validates the exact requested version in the native controller before stopping mining.
- The accompanying backend flags repeated errors from a currently running miner in the admin attention list and monitoring API, even when its aggregate rate is nonzero. Old backlog and previous-run errors are excluded; maintenance and rule controls remain available.
- Monitoring rule fields and bounds are documented in OpenAPI.

Windows Setup supports in-app updates; Portable requires manual replacement. Linux updates require running the AppImage. Downloading remains automatic; installation requires an explicit local/admin action. Previously running enabled processes are eligible to resume after a successful installation.

Verification uses disposable rigs, fake processes and real updater downloads with inert files. Packages are cross-built; real installer execution/relaunch and mining hardware behavior are not proven by these tests. Engine versions and protection settings are unchanged.
