# MineMaster 1.4.11

- Stop checking/installing unused engines at startup based on legacy CPU/GPU slot names. Prepare and verify the selected engine when launching or performing explicit maintenance.
- Prevent old XMRig file diagnostics from appearing as Nanominer CPU failures after an engine change.
- Keep process-exit and failed-Stop errors visible until resolved. A late file check cannot overwrite a newer launch or lifecycle failure.
- Make desktop Stop All check both slots for surviving managed processes, including slots reported stopped.
- Recognize managed SRBMiner survivors whose command line starts with a basename, using the resolved executable path and exact slot log argument to establish ownership. Fix Windows argument splitting after unquoted trailing backslashes.

Engines remain SRBMiner 3.7.0, Nanominer 3.10.0 and XMRig 6.26.0. No miner profile, automatic crash-recovery policy, clock or antivirus setting is changed.
