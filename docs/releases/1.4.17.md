# MineMaster 1.4.17 — KRig pool configuration fix

KRig requires SSL when connecting to Kryptex. This release rejects plaintext Kryptex settings and the known TCP ports in both primary and backup pools, before a miner can fail during startup. Select TLS and port 8049 for Quantus or 8048 for Pearl. New KRig selections default TLS on, with matching admin guidance and backend validation. Third-party TCP pools remain supported.

The saved Quantus/Pearl KRig profiles were corrected on production. FrontDesk successfully installed 1.4.16 automatically and launched KRig 1.5.6 after the SSL correction; CPU Nanominer remained independent. The mining engines are unchanged in 1.4.17. Existing rig assignments remain unchanged.

Published through the normal stable automatic-update channel. Validation: 146 client tests and 143 backend tests pass, including primary/backup transport and port checks. Real Windows launch and fresh API hashrate were observed; this does not establish overnight stability or future Windows Security behavior.
