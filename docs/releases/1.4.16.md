# MineMaster 1.4.16 — KRig trial

This candidate adds **KRig 1.5.6** for GPU Quantus and Pearl on Windows/Linux x64. Existing CPU/GPU engine choices stay unchanged. KRig does not mine Ravencoin or Monero; Nanominer and the other existing engines remain available.

- Select KRig in GPU settings on the desktop or admin, save a coin profile and deliver it to a client advertising KRig support.
- Preserve scoped Play/Pause, configuration acknowledgments, diagnostics, explicit repair, file logging and bounded opt-in crash recovery.
- Read aggregate hashrate and share counters from KRig's loopback HiveOS API. Missing, failed or frozen responses do not become zero or fresh samples. CPU mining runs independently.
- Verify official archive/executable hashes and retain upstream licensing notices. No changes to Windows Security, executable names or quarantine behavior.
- KRig's published developer fees are 0% on Kryptex and 3% on other pools; pool fees are separate. GPU models and driver/runtime requirements still need a trial. Linux AMD requires HIP; MineMaster does not install drivers/runtime packages.

Publish as a **prerelease**, leaving the stable fleet update channel on 1.4.15. Install the candidate manually on one Windows rig before expanding rollout. Automated tests use fake processes and disposable data; they do not establish Windows permission, real pool acceptance or throughput.
