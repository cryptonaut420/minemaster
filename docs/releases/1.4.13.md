# MineMaster 1.4.13

- Record native starts, parent exits and confirmed/failed Stops with process/run IDs in the existing rotating diagnostic logs. Launch wallets, passwords and arguments are not added to these records.
- Report when a previously observed miner log disappears, clear stale partial lines, and resume reading safely when the file returns.
- Prevent synchronous/asynchronous logging callback failures from interrupting file monitoring or native controls.

Paired backend fix: Stop, pause and removed-process transitions close chart history consistently with the existing five-minute clock tolerance, preserving original sample times and missing-versus-zero semantics.

Engine versions remain SRBMiner 3.7.1, Nanominer 3.10.0 and XMRig 6.26.0. No profile, protection setting, automatic recovery policy or forced fleet installation is changed. Hardware/driver/file-policy faults still require observation on the affected machine.
