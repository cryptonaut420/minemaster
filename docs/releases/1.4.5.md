# MineMaster 1.4.5

Reliability follow-up to 1.4.4, retaining its direct admin Play/Pause controls and Windows Nanominer file reporting repair.

- Update checks discover newer releases even when an older installer is downloaded. Failed refreshes preserve the ready installer; checks and installation cannot race.
- Dead connections reconnect without waiting for a lost close handshake; retired sockets cannot deliver late commands. Saved browser preference failures cannot interrupt reporting startup.
- Nanominer startup failures retain their final file-only error output, with independent CPU/GPU ownership.
- Backend monitoring flags a running process with missing/stale hashrate after startup grace.
- Complete Windows/Linux releases are built and verified before publication; both updater feeds and all uploaded asset digests are checked.

Windows Setup supports in-app updates; Windows Portable requires manual replacement. Linux updates require running the AppImage. Downloads remain automatic; installation requires an explicit local/admin action. Previously running enabled processes are eligible to resume after successful installation. Offline apps must reconnect before remote commands work.

Validation uses simulated rigs/native processes and actual updater download code with inert files. This release is cross-built and does not claim real Windows/Linux installer or mining hardware validation. Miner engine versions and protection settings are unchanged.
